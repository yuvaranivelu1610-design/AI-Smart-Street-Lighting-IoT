# AI Based Adaptive Smart Street Lighting and Traffic Monitoring System Using IoT Sensors

## Project Overview

This project focuses on designing an adaptive street lighting and traffic monitoring control system using Verilog HDL. The design is developed and simulated using Xilinx Vivado.

## Objectives

* Develop adaptive street lighting control logic.
* Process traffic-related input signals.
* Control street light LED outputs based on input conditions.
* Verify the design through Vivado simulation.

## Tools Used

* Xilinx Vivado Design Suite
* Verilog HDL
* Vivado Simulator

## Working Principle

The Verilog design processes the input signals and generates corresponding LED output signals based on the implemented logic. The behavior is observed and verified through Vivado simulation waveforms.

## Files Included

* `smart_street_light.v` — Verilog source code.
* `project_1.xpr` — Vivado project file.

## Simulation

The design was simulated using Xilinx Vivado. Simulation output screenshots can be added to this repository for reference.

## Future Enhancements

* Connect real IoT sensors.
* Implement the design on an FPGA board.
* Extend the system with real-time traffic analysis and AI-based control.

## Project Status

Verilog design and Vivado simulation completed.
